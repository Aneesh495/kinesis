# Kinesis Reproducibility Guide

This guide describes how to replicate experimental results, run deterministic seeds, verify exact mathematical benchmarks, and audit evidence packages.

---

## 1. Deterministic Seeding Protocol

All randomized components across Kinesis are seeded through explicit integers:
1. `dm_control` environments: `DMControlAdapter(task_name, seed=seed)`.
2. PyTorch models: `torch.manual_seed(seed)`.
3. NumPy random generators: `np.random.default_rng(seed)`.
4. Policy evaluation seeds: paired seed matrices across nominal and shifted conditions ensure that counterfactual comparisons experience identical starting states.

To run tests deterministically:
```bash
pytest tests/ -v
```

---

## 2. Floating-Point Precision and Hardware Invariance

- **Torch Precision**: `torch.float32` by default for all neural network operations.
- **Analytic Fixtures**: `np.float64` for high-precision algebraic Riccati solvers and Kalman matrix inversions.
- **MPS / CUDA / CPU**: Deterministic fallback to CPU BLAS for tests requiring strict bitwise reproducibility.

---

## 3. Cryptographic Verification of Artifacts

Any bundle generated by `make acceptance` produces a `MANIFEST.json` containing cryptographic SHA-256 digests. To independently audit any evidence directory:

```bash
python -m kinesis.artifacts.verifier --evidence <path_to_bundle>
```

The verifier executes:
1. Hash verification for every registered file.
2. Direct recalculation of episode returns from individual transition rewards.
3. Privacy audit asserting zero privileged simulator keys in observations.
4. Completeness check confirming all 7 distribution profiles are represented.
